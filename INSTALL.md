# Applying this drop

Everything here is source. `node_modules`, `functions/lib` (compiled output),
`functions/package-lock.json`, `*.tsbuildinfo` and the Expo web cache are
excluded — all of it regenerates from the manifests.

## 1. Install

```bash
pnpm install                       # workspace root
cd artifacts/mobile && npx expo install expo-gl expo-asset   # SDK-matched
cd ../../functions && npm install
```

`three`, `@react-three/fiber`, `@react-three/drei` and `@types/three` are
already in `artifacts/mobile/package.json`; the root `pnpm install` picks them
up. Run `npx expo install expo-gl` rather than trusting the pinned version —
it resolves against the installed Expo SDK.

`metro.config.js` now registers `glb`, `gltf`, `bin` and `hdr` as asset
extensions — without that the bundled base mesh 404s at runtime.
`unstable_enablePackageExports` was already `true`, which is what lets
`@react-three/fiber/native` and `three/examples/jsm/*` resolve.

The avatar assets (`artifacts/mobile/assets/avatar/*.glb`: the `sd_base_v2`
character, 3.0 MB, plus 19 garment templates, 2.6 MB together) are generated by
`artifacts/mobile/scripts/avatar/` and committed. See `AVATAR_3D.md`. Saved
avatars that name the old `sd_base_v1` still validate and render on v2.

Re-seed the catalog after deploying (`node scripts/seed-catalog.mjs`): items
now carry a `model` field naming their 3D template, and nine new items use the
new templates. Older documents without `model` still render (the template is
inferred from the id).

## 2. Deploy the rules first

```bash
firebase deploy --only firestore:rules,firestore:indexes
```

`users` and `bets` were both listable by any signed-in client. That is the
only change in this drop that is exploitable by anyone with the app installed,
so it goes out before anything else.

## 3. Deploy functions

```bash
firebase deploy --only functions
```

Changed: `sportsProvider` (real moneylines plus the team and venue data the
app was discarding), `placeBet` (odds-drift guard), `prizes` (the box that
never reached `ready`), `pruneGames` (no longer deletes games with pending
bets).

The first `syncGames` run after deploy backfills the new fields onto existing
`games/*` documents by merge. Cards render the old way until it lands — every
new field is optional.

## 4. Run

```bash
cd artifacts/mobile && pnpm dev
```

Check the Friends tab console first: the "Maximum update depth exceeded"
storm should be gone. Then check the avatar on a real device before web — web
is the easier GL target and will hide native problems.

## What changed

`QA_REPORT.md` — findings, severity, and the reasoning behind each rewrite.
`PATCHES.md` — the in-place diffs, all of which are **already applied** in
this tree. It is kept as a record of what moved and why, not as a to-do.
